# Seoul Season — Christmas Gift Box Landing Page Demo

A premium landing page concept for a Canadian online Korean gift box experience.

**Project:** Seoul Season — A Taste of Korea to Share  
**Purpose:** Demonstrate an e-commerce landing page and the customer-facing experience designed for an AI-powered order automation case study.

## Project Overview

Seoul Season is a concept for a Canadian online store offering curated Korean Christmas gift boxes.

The landing page presents three gift box options and guides visitors through a pre-order experience. It was designed as the customer-facing component of a broader e-commerce automation project built and tested locally with n8n.

## Gift Box Offers

| Box | Price (CAD) | Contents |
|---|---:|---|
| Seoul Mini | $12.99 | 4 products |
| Seoul Holiday | $24.99 | 8 products |
| Seoul Celebration | $34.99 | 12 products |

Each box combines Korean snacks and drinks.

## Project Objectives

- Create a premium, responsive landing page.
- Present the gift box range and pricing clearly.
- Design a simple pre-order customer journey.
- Demonstrate how a landing page can connect to an automated e-commerce workflow.
- Provide a public, accessible visual demonstration of the case study.

## Technical Background

The original e-commerce workflow was developed and tested locally using:

- **n8n:** workflow automation and order-processing logic.
- **HTML and CSS:** landing page structure and visual presentation.
- **Docker Desktop:** local n8n environment.

The locally tested workflow includes order data preparation, order identification, stock availability checks, reservation logic, customer and administrative email notifications, and reservation expiry handling.

## Demo Scope and Limitations

This public repository is intended for demonstration purposes only.

- No real products are sold through this page.
- No real orders or payments are processed.
- The public demo does not connect to the local n8n instance.
- Any order confirmation and reference displayed by the demo are fictitious.
- No inventory is reserved and no emails are sent.
- The local automation workflow is separate from this public landing page.

The automation workflow was tested locally. The public GitHub Pages website does not reproduce or operate the complete backend workflow.
